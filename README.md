# 中興大學出勤系統 - 學習日誌自動填寫

一支 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）使用者腳本，用來自動化中興大學工讀出勤系統（`https://psf.nchu.edu.tw/`）「學習日誌」的填寫流程：指定日期範圍與需要天數，自動跳過六日挑出工作天，逐筆送出，全部完成後再自動帶你到「學習日誌列印」頁面並帶入查詢條件。

> ⚠️ 這支腳本只是替你把「原本要手動重複打好幾次」的表單欄位自動填好、按下送出，本質上跟你自己一筆一筆手動填寫做的事情完全相同，沒有繞過系統的任何驗證或限制。使用前請詳閱下方「注意事項」。

## 功能特色

- **日期範圍 + 需要天數**：只要填「起始日期」「結束日期」「需要幾天」，腳本會自動在範圍內挑出工作天（週六、週日自動跳過）。
- **排除日期**：範圍內若有國定假日、補假等腳本判斷不出來的日子，可以手動填在「排除日期」欄位（逗號分隔），會一併跳過。
- **日期輸入雙模式**：起訖日期欄位可以直接手打（格式 `yyyy-mm-dd`），也可以按旁邊的 📅 按鈕叫出日曆選擇，兩者會自動同步。
- **校內編號下拉選單**：自動讀取系統表單裡現成的「校內編號」選項，跟系統上的清單保持一致，不需要手動維護。
- **可勾選調整**：產生日期清單後，可以個別取消勾選不要送出的日期。
- **中斷自動接續**：送出過程中若網站把頁面整個重新整理，腳本會自動偵測並從中斷的地方繼續處理剩下的日期，不需要重新操作。
- **自動接續到列印頁**：全部送出完成後，自動切換到「學習日誌列印」頁面，並帶入相同的校內編號、日期範圍，省去重新輸入的麻煩（實際的「列印 →另存為 PDF」仍需自己手動點擊，這是瀏覽器的安全限制，任何腳本都無法代勞）。

## 安裝方式

1. 先在瀏覽器安裝 [Tampermonkey 擴充功能](https://www.tampermonkey.net/)（支援 Chrome、Edge、Firefox 等主流瀏覽器）。
2. 點擊瀏覽器工具列的 Tampermonkey 圖示 → **管理面板（Dashboard）**。
3. 點右上角「**+**」新增腳本，把本專案 [`nchu-study-log-autofill.user.js`](./nchu-study-log-autofill.user.js) 的內容整份貼上，取代預設內容。
4. 按 `Ctrl+S`（或選單裡的「儲存」）儲存腳本。
5. 開啟 `https://psf.nchu.edu.tw/` 並登入，進入「學習日誌」頁面，畫面上方應該會自動出現一個黃色的操作面板。

### 使用 Chrome / Edge（Manifest V3）需要額外開一個權限

較新版本的 Chrome/Edge 預設會擋掉使用者腳本注入，如果照上面步驟裝完卻完全沒反應（連 console 都看不到腳本印出的訊息），請確認：

1. 網址列輸入 `chrome://extensions`（Edge 則是 `edge://extensions`）。
2. 打開右上角「**開發人員模式**」。
3. 找到 Tampermonkey，展開詳細資料，確認「**允許使用者指令碼**」（Allow User Scripts）這個開關是打開的。

## 使用方式

1. 進入「學習日誌」填寫頁面，畫面上方會出現「🔧 學習日誌自動填寫（腳本面板）」。
2. 依序確認／修改：起始日期、結束日期、需要天數、排除日期、工作內容、校內編號。
3. 按「**產生日期清單**」，下方會列出實際會送出的日期，可自行取消勾選不要的日期。
4. 按「**開始自動填寫**」，會先跳出確認視窗，確認後開始逐筆自動送出。
5. 送出過程中若頁面被重新整理，面板會自動重新出現並顯示「偵測到尚未完成的批次…自動接續處理」，不需要手動介入。
6. 全部送出完成後，會自動切換到「學習日誌列印」頁面並帶入查詢條件，此時**請自行點擊「列印」按鈕**，在跳出的瀏覽器列印視窗中選擇「另存為 PDF」完成存檔。

其他面板功能：

- **清除本機已完成紀錄**：清掉目前校內編號在本機瀏覽器記錄的「已送出」清單（不會影響系統上實際已經送出的資料）。
- **取消目前批次**：中止還在進行中的自動送出佇列，剩下未送出的日期不會再繼續處理。

## 注意事項

- 這是個人為了節省重複手動操作時間所寫的工具，**不隱藏、不繞過**系統本身的任何確認流程；每一筆送出前後都可在畫面上的紀錄區看到即時進度。
- 腳本只在瀏覽器本機執行、只操作 `psf.nchu.edu.tw` 網域上的表單欄位，不會把你填寫的任何資料傳送到本專案以外的任何伺服器。
- 送出前請務必確認日期範圍、工作內容、校內編號是否正確；自動化不代表不需要覆核，尤其是第一次使用時建議先用少量日期測試。
- 校內編號、工作內容屬於個人/專案資訊，若要把自己客製化後的版本分享給其他人，記得提醒對方修改成自己的內容，不要直接照搬你的預設值。
- 「另存為 PDF」這一步刻意設計成需要使用者手動點擊，這是瀏覽器對網頁腳本的安全限制（無法用程式碼控制原生列印/存檔對話框），並非腳本功能不完整。
